How does AI Folder Sync work?

Link your local folder once and collaborate directly with your favorite AI assistant without manually copying or creating files.

Start a new or existing project

  1. 1
    Choose your project folder: In Step 1, select an existing or empty folder on your computer. All code and configuration files across any programming language are recognized and selected automatically.
  2. 2
    Type your task & copy: Choose your desired AI Output Limit, describe what you want to build in Step 2, click Full project + prompt, and paste it into your AI assistant.
  3. 3
    1-Click build & automatic backup: Copy the AI's JSON code block and click Read clipboard & update folder. An automatic backup is saved first so you can always undo or switch versions.

Ongoing chat, Sync & Version History

  1. 1
    Automatic detection: When you edit, rename, move, add, or delete files or subfolders in VS Code or Explorer, AI Folder Sync detects it in the background and highlights the Sync button.
  2. 2
    Smart Sync (grouped folder & file diffs): Use Sync + prompt to send only your manual changes. Renamed or deleted subfolders are grouped as 1 change without resending unchanged code.
  3. 3
    Version History & Part-2 Recovery: Not happy with an AI update? Click Undo last update or pick any version in Version History. Cut-off JSON responses are also detected automatically.

Key Features

Designed for speed, clarity, and projects of any size or programming language.

Live Auto-Sync & All Languages

Supports all programming languages, scripts, and config files. Automatically detects file edits and folder/file renames or deletions in the background.

Version History & Floating Panel

Every update is backed up automatically so you can undo with 1 click or switch between versions anytime—even from the compact floating panel on top of your AI chat.

Configurable Output Limit & Part-2 Recovery

Choose how many lines of code the AI may generate per message (350, 700, 2,000, or unlimited) and recover cut-off JSON responses with 1 click.

100% Local & Open-Source

Your source code and files never leave your device to any external server through this tool.

Full privacy in your own browser

This tool runs completely client-side via the official W3C File System Access API.

  • Works with every AI: Use ChatGPT, Claude, Gemini, DeepSeek, or local LLMs.
  • 0 bytes to external servers: Everything is processed locally in your browser's memory.
  • Direct disk access: Files and subfolders are updated directly inside your linked folder.
